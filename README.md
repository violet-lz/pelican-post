# 鹈鹕邮差 · 今天，顺风。

固定侧视角的无尽骑行送信游戏。项目保留原版 HTML 中的鹈鹕、自行车、喉囊小鱼、花束与风车，使用 Vite、TypeScript、PixiJS 8 和 React 19 建立独立工程。

## 启动

在这个目录运行：

```sh
npm install --registry=https://registry.npmjs.org
npm run dev
```

打开 <http://127.0.0.1:5178/>。当前电脑的依赖已安装，也可以双击项目内的「启动鹈鹕邮差.command」。存档属于浏览器及这个本地网址；更换浏览器、网址或电脑前，可以先导出 JSON 备份。

## 当前可玩内容

- 动态主页、三个独立存档、默认远视野和随时切换的近视野。新存档直接自动巡航，首个邮局由玩家按 E 停靠。
- W/S 平滑换路、坡道高桥与支路、A 刹车并保持朝向后退、Q 连续掉头、D 启动或加速、跳跃与鸣铃。A 刹至零或倒骑后松开，平滑停到精确的 0，直到重新按 D 才恢复巡航；停车状态随存档保存。碰到路边障碍只会减速。
- 场景内邮局桌子抽屉打开，右侧卡片选择取信；容量校验、同批起始计时、逐封评级、金币与好评、退件费用。
- 抽屉整批妥投才补信；去过其他地区再回访也可补充。旧的在途信件保留，不由新批次覆盖。
- 海岸与沙漠的分支和往返；六种主题的基础地标与地址随等级开放，每区五处不同地标。后四种主题目前是供继续扩展的基础场景。
- 两区回退窗口、封路告示、目的地区退出窗口后的循环信冻结与重访交付、白鸽路线引导。
- Lv2 路边小商品卡、容量升级和小幅被动加成；基础昼夜、连续日月移动、2 分钟一天、4 天一季。
- 自动投递辅助、手账、基础成就进度、15 秒自动存档与关键事件存档、前两份恢复快照、导入导出及单页面写入保护。

天气过程、雨滩与雪堆、天气装备和自理动作、动物朋友及喂食尚未接入。当前版本先验证文档第一个阶段的可玩与存档闭环；完整的四季地域表现和两小时长测属于后续验收。

## 操作

| 按键 | 行为 |
| --- | --- |
| W / S | 上下换到相连道路 |
| A（按住） | 刹车后倒骑，保持朝向；刹至零或倒骑后松开会平滑停稳 |
| D | 停车后重新按下恢复巡航；按住消耗少量体力加速 |
| Q | 平滑掉头 |
| 空格 | 跳跃 |
| E | 投递、停靠邮局或商店、离开停靠 |
| B | 车铃 |
| 1 / 2 / 3 | 购买路边对应物品 |
| Esc | 暂停或关闭面板 |

取信、停靠互动、设置、手账、暂停、后台和离线均冻结游戏与信件时钟。普通路边停车及商品预览继续计时。

后续需求与调整统一维护在 [游戏玩法设计.md](./游戏玩法设计.md)，并随实现一同提交。

## 验证与工程

```sh
npm test
npm run build
```

`src/game` 负责固定步长模拟、骑行启停、信件和交易；`src/world` 负责地区、路线、分块和画面；`src/storage` 负责快照校验、写入事务和浏览器互斥锁；`src/ui` 负责交互面板。用于角色图集的原始 HTML 随工程保存在 `reference/original-coastal-ride.html`。

## GitHub 与网页发布

源码公开仓库：<https://github.com/violet-lz/pelican-post>。

在线游戏：<https://violet-lz.github.io/pelican-post/>。

推送到 `main` 时，`Verify game` 工作流自动执行测试、正式构建并保存可部署网页产物。Vite 使用相对资源路径，角色图集也遵守站点基础路径，支持 GitHub Pages 的项目子目录。

按用户确认，仓库设为公开，使用 GitHub Actions 发布 GitHub Pages。`Deploy GitHub Pages` 在推送 `main` 时自动测试、构建、部署，也可在 Actions 页面手动运行。

线上网址与本地网址使用各自独立的浏览器存档；本地进度通过导出 JSON 后在线上导入即可迁移。

`scripts/bake-actor.mjs` 从原始 SVG 动画生成 144 帧图集。图集作为公共素材常驻，地区纹理仅保留两区及一个受控预览，附近最多 5 个逻辑地图块。场景过渡只保留一张临时纹理，并在 1 秒后释放。

`scripts/qa-browser.mjs` 在隔离浏览器中检查真实交互、100 次跨区、资源上限、恢复快照与导入导出，并把截图写到 `qa/`。`scripts/qa-site.mjs` 从页面验证正式构建和线上站点，不依赖开发调试入口。`scripts/qa-performance.mjs` 默认进行 30 秒真实渲染采样；设置 `PELICAN_SOAK_SECONDS=7200` 可单独运行两小时验收。

浏览器检查使用项目开发依赖 Playwright，默认启动本机 Chrome；可用 `PELICAN_CHROME_PATH` 指定可执行文件，或用 `PELICAN_BROWSER_CHANNEL` 指定浏览器通道。这些开发依赖不进入网站运行包。
